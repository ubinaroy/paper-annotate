# paper-annotate · 论文互改批注工具

在浏览器里对论文 PDF **逐句 / 逐区域**写批注，批注自动存成结构化文件和一份 Markdown。Markdown 里带原句和 `.tex` 行号，可以直接交给 Claude 等 AI 改稿。互改时，各人在自己电脑上批注，把导出的文件发给作者，作者「导入」后统一处理。

- 只依赖 **Python 3.9+ 标准库**，网页用 CDN 上的 pdf.js，不用装任何东西
- 论文不上传到任何服务器，服务只监听本机

## 快速开始

```bash
git clone <本仓库> && cd paper-annotate
python3 server.py path/to/main.pdf
```

打开终端里打印出的地址（默认 <http://localhost:8791>）。批注数据存在当前目录的 `annotate-data/`；想放别处就加 `--data <目录>`。第一次启动之后，PDF 路径会记在数据目录里，再启动只要 `python3 server.py`（加上同样的 `--data`）。`serve` 子命令可写可不写。

## 怎么批注

| 操作 | 结果 |
|---|---|
| 点一下某句话 | 选中整句，弹出输入框 |
| ⇧ 点另一句 | 把范围延伸到那一句 |
| 拖选文字 | 任意文字（自动吸附整词，可跨页） |
| `R`，或按住 ⌥ 拖框 | 区域批注：图、表、公式、整段 |
| 侧栏「+ 整体意见」 | 不针对具体位置的意见 |
| ⌘↵ / Esc | 保存 / 取消 |
| `J` `K`、点页边的编号 | 在批注之间跳转 |
| 双指捏合、⌘+ / ⌘−、Ctrl+滚轮 | 以光标为中心缩放；⌘0 适合宽度 |
| 拖 PDF 与侧栏之间的竖条 | 调侧栏宽度（双击恢复） |

每条批注可以打标签（改写 / 删减 / 逻辑 / 疑问 / 图表 / 格式），状态分为未处理 / 已改 / 待讨论。第一次写批注时会让你填名字，之后每条都带上署名。顶栏「署名」可以随时改；也可以启动时加 `--author 你的名字` 设成默认署名（记在数据目录里，换浏览器也生效）。

## 互改流程

1. **作者**把编译好的 PDF 发给大家（同一份文件即可，不需要源码）。
2. **审稿人**各自运行 `python3 server.py 收到的.pdf`，批注完点顶栏「**导出**」，得到一个 `annotations-….json`，发回给作者。
3. **作者**在自己的页面点「**导入**」，选这些文件。别人的批注会合并进来，重新编号，每条标明是谁写的，侧栏可以按人筛选。
   - 工具按 PDF 内容判断是不是同一份稿子，不认文件名，所以对方改了文件名也没关系。如果对方批的是旧版本 PDF，会导进你当前打开的那一轮，并提示位置可能有偏差。
   - 同一个文件导入两次不会重复：同一条批注只保留较新的版本。
4. 作者改稿后重新编译，页面顶部会提示「用最新 PDF 开新一轮」。旧轮次在左上角下拉框里，批注位置永远对得上它自己那份 PDF 快照。

## 交给 AI 改稿

每一轮的数据在 `<data>/R<编号>_<编译时间>/`：

| 文件 | 内容 |
|---|---|
| `annotations.md` | 给人和 AI 读的版本：原句、`file:line`、批注人、标签、状态、回复 |
| `annotations.json` | 完整数据（网页、导入导出都用它） |
| `main.pdf`、`src/` | 这一轮的 PDF 快照和 `.tex` 源码快照 |
| `crops/*.png` | 区域批注的截图 |

例如对 Claude Code 说：「按 `annotate-data/R03_…/annotations.md` 改稿，每条改完用 `server.py reply` 回复」。

```bash
python3 server.py reply R03_20261116-2010 7 "已拆成两句" --status done   # 回复人默认 Claude，可用 --by 改
python3 server.py new-round                                            # 命令行开新一轮
python3 server.py md R03_20261116-2010                                 # 重新生成并打印 Markdown
```

回复会在打开着的页面里 5 秒内显示出来。

## 可选依赖（有就更好用）

| 工具 | 来源 | 没有它时 |
|---|---|---|
| `synctex` | TeX 发行版自带（TeX Live / MacTeX） | 批注不带 `.tex` 行号，AI 只能按原句去找 |
| `pdfinfo`、`pdftoppm` | poppler（`brew install poppler` / `apt install poppler-utils`） | 页面尺寸改由浏览器测量；区域批注不生成截图 |

要有行号，PDF 需要用 `-synctex=1` 编译（latexmk、Overleaf 下载的源码本地编译都默认开启），并且 `main.synctex.gz` 和 PDF 在同一个目录。源码目录不在 PDF 旁边时，用 `--tex-dir` 指定。

## 其他参数

```
python3 server.py serve [PDF] [--data DIR] [--tex-dir DIR] [--author 名字] [--port 8791] [--host 127.0.0.1]
```

端口被占用时会自动往后找空闲端口。`--host 0.0.0.0` 可以让局域网里的人直接连你的页面，但目前**没有登录和权限控制**，只在可信网络里用。
